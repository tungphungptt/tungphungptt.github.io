Privacy Policy — AI Video Tool

Last updated: 22 November 2026

AI Video Tool ("the tool") is a personal desktop application that runs entirely on its owner's own computer. This policy explains how it accesses, uses, stores and shares Google user data.

1. Google user data accessed

  • youtube.upload — to upload videos and thumbnails that the user created with the tool to the user's own channel.
  • youtube.readonly — to read the name of the connected channel so the tool can show which channel is connected.
  • youtube.force-ssl — to upload subtitle (caption) files for those videos.

2. How the data is used

The data is used only to perform the actions the user starts in the tool: uploading or scheduling their own videos, thumbnails and captions, and displaying the connected channel name. It is not used for advertising, profiling, or any other purpose.

3. Storage

The OAuth access/refresh token is stored only on the user's own computer (in the tool's local secrets folder). The tool has no server; no Google user data is sent to or stored by the developer or any third party, other than Google/YouTube itself.

4. Sharing

Google user data is not sold, transferred or shared with anyone. AI Video Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

5. Deleting data / revoking access

Delete the token file from the tool's secrets folder, and/or revoke access at any time at Google Account → Third-party connections.
